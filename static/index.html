Add your API key

You bring your own key so usage is billed to your own account. Add the key for whichever model you pick — Gemini (Google) or Claude (Anthropic).

Gemini key (Google): create one at AI Studio for the Gemini models.
  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. Click Create API key (pick a Google Cloud project, or let it make one).
  3. Enable billing on that project (Set up billing) to move the key onto a paid tier.
  4. Copy the key — it looks like AIza… — and paste it below.
Anthropic key (Claude): create one in the Anthropic Console to use Claude Haiku 4.5 and Sonnet 5. It looks like sk-ant-…. Claude users don't need a Gemini key (image generation stays Gemini-only).
⚠️ A free-tier Gemini key won't work here. Each message fires several model calls, which blows past the free tier's per-minute limit and fails with a 429 quota error. Use a billing-enabled (paid tier) key.
🔒 Your key(s) are kept only in this browser tab (session storage). They're sent with each request to power the AI and are never saved on our server. Closing the tab or logging out erases them — you'll re-enter them next time. Treat them like passwords and don't share them.
