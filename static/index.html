Add your Gemini API key

This app uses Google's Gemini models. You bring your own key so usage is billed to your own Google account.

What is this? A Gemini API key is a secret token that lets this app make AI requests as you. You create it at Google AI Studio.
  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. Click Create API key (pick a Google Cloud project, or let it make one).
  3. Enable billing on that project (Set up billing) to move the key onto a paid tier.
  4. Copy the key — it looks like AIza… — and paste it below.
⚠️ A free-tier key won't work here. Each message fires several model calls, which blows past the free tier's per-minute limit and fails with a 429 quota error. Use a billing-enabled (paid tier) key. Pick the gemini-3.1-flash-lite model and light use runs only fractions of a penny.
🔒 Your key is kept only in this browser tab (session storage). It's sent with each request to power the AI and is never saved on our server. Closing the tab or logging out erases it — you'll re-enter it next time. Treat it like a password and don't share it.
